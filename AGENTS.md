# Istruzioni del progetto

Prima di iniziare ogni nuova attività, leggi il file `CLAUDE.md` nella radice del repository e segui le istruzioni applicabili in esso contenute. `CLAUDE.md` è la fonte di riferimento per le istruzioni condivise del progetto.

Poi leggi `Design/regole.md` (regole di lavoro: git, test, CHANGELOG, passaggio tra agenti) e seguile.
